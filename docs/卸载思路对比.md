# 冰点还原：多种卸载思路对比

> 这份文档不教具体命令，只帮你**选对路线**。具体操作见 [使用说明](../使用说明.md)。
> 每条路线都标了：前提、耗时、风险、以及在什么情况下会失败。

---

## 一、先看这张决策图

```
你有冰点密码吗？
├─ 有 ──────────────────────────────► 【1】官方卸载（最省事，优先）
└─ 没有
   ├─ 是企业版、且有控制台权限？ ─────► 【2】一次性密码 OTP
   ├─ 是未输序列号的试用版？ ─────────► 【3】BIOS 时钟法
   ├─ 知道机器有定时"解冻窗口"？ ─────► 【4】窗口内在线卸载
   └─ 都不行（最常见）
      ├─ 能插 U 盘 + 能进 PE ─────────► 【5】PE 离线摘除  ★本工具主路径
      ├─ 不想做 U 盘、但系统自带恢复环境 ─► 【6】WinRE
      ├─ 机器上有第二套 Windows ───────► 【7】借另一套系统
      └─ 以上都不行 ───────────────────► 【9】重装系统（兜底）
```

**一句话原则**：冰点冻结的是"系统盘上的写入"，所以**必须在"它的驱动没加载"的环境里动手**。
PE、WinRE、另一套 Windows —— 本质都是同一类环境，区别只是"怎么进去"。

---

## 二、逐条分析

### 【1】官方卸载（有密码）

- **前提**：记得密码。
- **步骤**：冰点界面 → 启动后解冻 → 重启 → 运行卸载程序 → 输入密码。
- **耗时**：5 分钟（含两次重启）。
- **风险**：几乎为零。
- **会失败吗**：不会，除密码记错。
- **评价**：有密码就用这个，别折腾。

### 【2】企业版一次性密码（OTP）

- **前提**：Deep Freeze **Enterprise**，且你能访问控制台 / 配置管理员。
- **步骤**：工作站登录框记录 Token 码 → 控制台 `工具 → 一次性密码` 输入 Token → 得到 OTP → 用它登录并卸载。
- **耗时**：2 分钟。
- **风险**：无。
- **会失败吗**：标准版没有此功能；拿不到控制台就用不了。
- **评价**：企业环境的正规解法，[官方文档](https://support.faronics.com/help/en-ca/29-deep-freeze-windows/101-i-installed-deep-freeze-and-forgot-my-password-can-you-give-me-a-password-to-turn-deep-freeze-off)有说明。

### 【3】试用版时钟法

- **前提**：**未输入序列号**的试用版。
- **步骤**：进 BIOS 把时间前推 60 天以上 → 启动后保护失效 → 正常卸载 → 再把时间改回。
- **耗时**：10 分钟。
- **风险**：改时间可能影响证书、域认证、双因素；**正式授权版完全无效**。
- **会失败吗**：绝大多数人用的是"已激活"版本，所以基本用不上。
- **评价**：官方给出的唯一"忘记密码"补救，但只对试用版成立。

### 【4】解冻窗口

- **前提**：管理员配置过"定时解冻"（机房常见，比如每晚 2:00–3:00）。
- **步骤**：在窗口内，系统不受保护 → 直接在线卸载（本工具 `[3]`）。
- **耗时**：取决于窗口。
- **风险**：窗口结束前没做完，改动会被还原（不至于变砖）。
- **会失败吗**：不知道窗口时间就没法用。
- **评价**：最"无痛"的路径，但前提是你知道排班。

### 【5】PE 离线摘除 ★本工具主路径

- **前提**：能进 PE（U 盘启动 / Windows 安装盘 `Shift+F10`），**系统盘没被 BitLocker 锁死**。
- **原理**：PE 里冰点驱动没加载，此时"摘注册表登记 + 删文件"是真正落到硬盘上的。
- **步骤**：`[2]` 生成离线包 → 进 PE → 双击 `一键卸载-触摸.cmd`（或 `[2]` 强制卸载）。
- **进 PE 不想按热键？** 用 `Start.cmd` 的 `[10]`：UEFI 一次性启动，只把"下一次启动"指向
  U 盘（不改 BIOS 顺序，失败自动回退，进过 PE 后自动恢复）。
- **耗时**：15 分钟。
- **风险**：中低。**顺序错了会蓝屏**（所以必须"先摘登记、再删文件"）；驱动文件被占用时需重启后删除。
- **会失败吗**：BitLocker 未解锁、盘符选错、PE 里没有 PowerShell 且用了 PS 版脚本。
- **评价**：**通用性最好**，不依赖密码、不依赖版本、不依赖厂商。

### 【6】WinRE（系统自带恢复环境）

- **前提**：WinRE 可用（或能 `reagentc /enable`）；有一个**没被冻结**的卷放脚本。
- **步骤**：`[6]` 一键准备 → 重启 → 疑难解答 → 高级选项 → 命令提示符 → 跑清理器。
- **耗时**：20 分钟。
- **风险**：中。冻结状态下 `reagentc /enable` 可能被还原；**RE 的命令提示符没有屏幕键盘**。
- **会失败吗**：恢复分区被删 / 镜像损坏 / 无键盘设备（进得去但敲不了命令）。
- **评价**：不想做 U 盘时的首选，但**无键盘设备别走这条**。

### 【7】借另一套 Windows（双系统）

- **前提**：机器上有第二个 Windows（双系统 / 另一块盘）。
- **步骤**：重启进那套系统 → 运行 `DF-Offline-Clean.ps1 -TargetWindows "C:\Windows"`。
- **耗时**：10 分钟。
- **风险**：低（只要别选错盘）。
- **会失败吗**：没有第二套系统就用不了；盘符在该系统里可能不同。
- **评价**：零额外介质的"离线环境"，很多人忽略。

### 【8】内核级工具（DeepThaw 这类）—— 评估后**不推荐**

- **前提**：能自己编译 VS+WDK 工程、能加载**未签名内核驱动**（关驱动签名强制 / 测试签名 / BYOVD）。
- **原理**：在内核里按名字找到冰点驱动对象，改它的 IAT、把判断指令改成 `mov al,1`，
  让"是否冻结"永远返回真值。不需要重启、不需要 PE。
- **耗时**：1–3 小时（含编译与调试）。
- **风险**：**高**。蓝屏（作者自己在源码注释里写了）、杀软/EDR 必报（物理内存映射 + IAT hook + 拦 IRP 是标准 rootkit 特征）、版本强绑定。
- **会失败吗**：冰点更新、驱动被签名策略拦下、内存映射失败。
- **评价**：确实能做到"不重启"，但代价与收益不成比例。详见 [DeepThaw-技术评估](DeepThaw-技术评估.md)。

### 【9】重装系统（兜底）

- **前提**：什么都试不通，且数据可备份。
- **注意**：**如果冰点仍处于冻结状态，"重置此电脑"可能被还原**；要干净就得全新安装（并把分区全删）。
- **耗时**：1–2 小时。
- **风险**：数据、驱动、授权。
- **评价**：最后手段。多数情况下【5】就能解决，不必走到这一步。

## 三、横向对比

| 方案 | 需要密码 | 需要介质 | 需要键盘 | 耗时 | 风险 | 通用性 |
|---|---|---|---|---|---|---|
| 【1】官方卸载 | 是 | 否 | 是 | 5 min | 极低 | 仅限记得密码 |
| 【2】OTP | 否 | 否 | 是 | 2 min | 无 | 仅企业版 |
| 【3】时钟法 | 否 | 否 | 是(BIOS) | 10 min | 中 | 仅试用版 |
| 【4】解冻窗口 | 否 | 否 | 是 | 依窗口 | 低 | 仅配过窗口 |
| 【5】PE 离线 | 否 | **U 盘** | 否* | 15 min | 中低 | **最好** |
| 【6】WinRE | 否 | 否 | **是** | 20 min | 中 | 中等 |
| 【7】另一套系统 | 否 | 否 | 是 | 10 min | 低 | 看机器 |
| 【8】内核工具 | 否 | 否 | 是 | 1–3 h | **高** | 版本绑定 |
| 【9】重装 | 否 | 视情况 | 是 | 1–2 h | 高 | 兜底 |

\* 无键盘时用触摸版 `一键卸载-触摸.cmd`：双击即全自动，见 [使用说明 第九章](../使用说明.md)。

## 四、常见失败原因对照表

| 现象 | 最可能的原因 | 处理 |
|---|---|---|
| 卸完重启，冰点又回来了 | ① 当时是冻结状态，在线删的被还原；② 硬盘上有 `hiberfil.sys`（快速启动）覆盖了注册表改动 | 改用【5】；清理器会提示删除 `hiberfil.sys` |
| 开机蓝屏 `0x7B` | 先删了驱动文件，但服务登记 / `UpperFilters` 还在 | 进 PE 再跑一次完整清理；或用 `DFBackup_*` 回滚 |
| PE 里"找不到 Windows 系统" | 盘被 BitLocker 加密 / 盘符不对 / 分区未挂载 | 先解锁；或 `-TargetWindows D:\Windows` 手动指定 |
| 清理器拒绝执行 | 不在 PE 里（安全阀） | 重启进 PE；调试才用 `/force` |
| `reg load` 报"拒绝访问" | 配置单元还被占用（上次没卸干净） | 重启 PE 后重试；或先删同目录 `.LOG` 文件 |
| 找不到 `Faronics` 目录 | 装的是别的还原软件（Rollback Rx 等） | 本工具只处理冰点，扫描会提示你另找方案 |
| 卸载后系统时间/授权异常 | 用了【3】时钟法但没改回来 | 进 BIOS 把时间改回 |

## 五、不要做的事

1. **不要先删驱动文件**。
   `DFFilter.sys` 删了、但 `Services\DFFilter` 和 `UpperFilters` 还在 —— 下次开机会去加载一个不存在的驱动，
   直接 `0x7B`。顺序永远是：**先摘注册表登记 → 再删文件**。

2. **不要在冻结运行中的系统里硬删**。
   写入会被重定向，重启全部还原，还可能留下"半残"状态。这是冰点的设计目的，不是工具不行。

3. **不要直接改裸磁盘扇区 / 内存打补丁**。
   前者极易把文件系统写坏；后者就是【8】，风险见上。

4. **不要用"替换 persi0.sys"这类来路不明的文件**。
   版本不匹配就蓝屏，而且那些文件通常来自非官方渠道 —— 本质是把系统安全交给陌生人。

5. **不要在有 BitLocker 的盘上跳过解锁**。
   PE 里读不到加密卷，硬来只会得到"找不到系统"。

## 六、怎么选（给不同人的一句话建议）

- **自己的笔记本/一体机，忘了密码** → 【5】PE 离线摘除（或【6】不想做 U 盘）。
- **无键盘触摸设备（希沃等）** → 【7】一键重启到恢复环境 + 触摸版自动卸载。
- **公司资产、有 IT 部门** → 走【1】/【2】，别自己动手。
- **网吧/机房维护** → 【4】解冻窗口最省事；否则用【5】批量处理。
- **只是想把控制权拿回来** → 卸了重装，重装时设新密码（本工具 `[8]` 可以先导出配置清单对照）。
